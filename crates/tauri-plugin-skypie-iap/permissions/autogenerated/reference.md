## Default Permission

Read this install's entitlement, list what is for sale, buy it, and restore a
previous purchase.

Every command here answers a question about ENTITLEMENT. None of them exposes
a receipt, a transaction, or a store credential to the webview, so granting
the set does not widen what rendered content could reach.

#### This default permission set includes the following:

- `allow-entitlement`
- `allow-offerings`
- `allow-purchase`
- `allow-restore`
- `allow-refresh`
